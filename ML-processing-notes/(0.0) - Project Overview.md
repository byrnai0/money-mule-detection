# 0. Project Overview

## Problem

Traditional AML systems mostly depend on predefined rules and thresholds. These approaches can produce many false positives and struggle to identify complex money-mule networks and hidden transaction relationships.

Our project aims to detect suspicious financial activity by representing transactions as a **graph** and applying **Graph Neural Networks**, with a later **quantum-inspired optimization layer**.

### Core idea

```
Financial Transactions
        ↓
Data Preprocessing
        ↓
Account-level Transaction Graph
        ↓
Feature Engineering
        ↓
Graph Neural Network
        ↓
Risk / Suspicion Detection
        ↓
Explainability
        ↓
Quantum-Inspired Optimization
```
